Put PresentMon.exe here.

1. Go to https://github.com/GameTechDev/PresentMon/releases
2. Download the console build (file name like PresentMon-2.x.x-x64.exe) — NOT the PresentMon installer/GUI.
3. Rename it to PresentMon.exe and place it in this folder.

It is copied next to Pulse.exe on build. Without it, Pulse still shows GPU/CPU/RAM; only FPS is off.
